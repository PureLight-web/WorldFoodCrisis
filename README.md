# Food Supply Watch

An independent, evidence-led publication about food availability, food prices, agricultural inputs, supply chains and food security.

## Technology
- Plain HTML, CSS and JavaScript
- GitHub source control
- Cloudflare Pages (static assets only; no Cloudflare Workers)

## Editorial principles
- Distinguish global commodity availability, affordability and localized acute food insecurity.
- Use official primary sources wherever possible and date every time-sensitive statistic.
- Avoid panic, unsupported predictions and keyword-led filler.
- Publish only pages with a clear reader purpose and original value.
